# Design references — external inspiration for the NEW site

*Consolidated 2026-08-26 during the clean-start decontamination.*

## What this is

Screenshots of **other companies' websites**, collected across the v4–v7 design
cycles. Every Beeond-specific design artefact from those cycles — the v7
Blueprint spec, moodboards, concept boards, copy decks, brand assets, the
art-direction prompts and the design playbook — was deleted. These captures
survived because they are raw external input, not prior Beeond direction, and
the project is about to run a fresh reference-gathering phase.

## What this is NOT

**No Beeond visual direction survives the reset.** Where the annotations below
prescribe a Beeond palette, typeface, or layout — "Beeond is cream", honey
yellow, Rubik, Hebrew-first display type, the cream/dark rhythm — that is
**retired v3–v7 direction and carries no authority.** Read those documents for
the *observations about other people's sites*, which are still good, and ignore
every sentence that tells you what Beeond should look like.

The new direction is undecided. Nothing here pre-commits it.
