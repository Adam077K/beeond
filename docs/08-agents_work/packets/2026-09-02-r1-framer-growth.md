## A. Site architecture

**Keeping the default four pages: Home · Approach · About · Book a Call.** The conversion-first lens gives no reason to change page count — the G2 spine's reasoning for exactly these four (every alternative round-out page — Pricing, Case Studies, Blog — requires evidence Beeond does not have) holds up under a CRO read too. What the conversion-first lens *does* change is what runs inside each page, and the order two of them run in. See §F for the full list of what moved and why.

This is storyboard §0.1 and cross-cutting rule 1 (the fast path) stated as one nav bar; there's no CRO argument for touching it.

**The fast path, stated plainly for this angle:** because the primary CTA is persistent in the nav on every page, "where the ask appears" below is never really one number — it's the nav CTA (always present, zero scroll required) plus whatever section-level asks a page adds on top. A visitor in S4 (warm, ready) never has to read a single section to convert; he clicks the nav button from second one. Everything below is designed for the visitor who *isn't* there yet.
