## 3. Three strongest, and why

**L-02 — the empty fifth row at H7.** The storyboard already decided there is no Beeond row. Drawing the row
anyway, ruled and unlabelled, turns that decision into the section's argument instead of its absence. It costs
one hairline, spends no moment, breaks no invariant, and it is the rarest thing in this slice: a device the
reference set does not contain, arrived at by inverting the one it does.

**L-10 with L-11 and L-12 — the cross as the site's small glyph.** Grid intersections, list bullets and the
rules themselves, all drawn from the mark's own hidden cross. Three cheap decisions that make the quiet
sections — which are most of the site — feel authored rather than merely restrained, without spending a single
signature moment. Sourced from two references, derived from the locked mark.

**L-03 — H1 and H10 are the same place, later.** Three of the six full pages bookend with one image, and it is
why they read as one page rather than a stack. It is also one shoot instead of two, and it makes the
"one photographic world" thesis literal at the two positions serial position says are remembered. It displaces
moment 3, which is the trade the founder should see stated.

## 5. What the index gets wrong

**Four findings. Two are gaps, one is a description I cannot verify, one is a wording problem in the brief
rather than the index.**

1. **The header count is wrong, and `L21` has no entry.** `_index-landing.md` opens "20 files. `L01`–`L20`"
   and its inventory table holds twenty rows. The directory holds **twenty-five** image files: `L01`–`L21`
   plus the four `NEW-*`. `L21` carries a descriptive filename and is cited by name in
   `ART-DIRECTION-BRIEF` §7 and §8 and in `DESIGN-LANGUAGE`'s source column, but the index never describes
   it. Anyone reading the index would conclude the file does not exist.

2. **`L05` — "portrait dissolved into a coarse diamond-halftone dot screen" is not verifiable.** What is
   visibly in the frame is an indistinct dark mass with one curved silhouette edge, dissolving to isolated
   marks toward the lower left. It may be a portrait; at this resolution it reads equally as a ridge line or
   as an abstract form. Suggested wording: "an indistinct subject dissolved into a coarse diamond-halftone
   screen — not legible as a portrait in this capture." The *technique* the index records is exactly right;
   only the subject is asserted beyond what the file shows.

3. **`L01` — one visible technique is unrecorded.** The capture is a browser mock on a desktop, and the
   desktop behind it is a vertical column of monospace characters running down both margins. The index
   describes only what is inside the browser frame. Minor, but it is a character-field technique sitting
   uncredited in a file the index reads as having none.

4. **`ART-DIRECTION-BRIEF` §8, not the index: "`L21` = `L11` (pixel-identical)."** As rendered, `L21` is the
   same composition **rotated 90°** — type reads bottom-to-top, the hands sit at opposite corners, the glyph

the dot fields and not of the page — the headline, deck and button all sit in that centre. That matters

reference actually *supports* putting H7's four rows in the cleared middle, which is what §4 already specifies.
